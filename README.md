# Куда Вайб?

Бот в мессенджере MAX, который помогает студентам чаще выбираться на мероприятия. Подбирает события по интересам, напоминает о выбранных и считает культурный стрик

## Стек

Python, maxapi, SQLAlchemy + asyncpg, PostgreSQL, Alembic, APScheduler, Docker Compose

## Как устроено

Логика диалога отделена от работы с базой, хендлеры не обращаются к базе напрямую, только через services

```
bot/
  main.py        запуск: бот, миддлвары, роутеры, планировщик
  handlers/      логика диалога: старт, регистрация, подборка, меню, админка
  keyboards/     кнопки
  texts/         тексты
  middlewares/   выдаёт сессию базы на каждый апдейт
core/database.py движок и сессии
models/          таблицы
services/        все запросы к базе
scheduler/       рассылки по расписанию
migrations/      миграции Alembic
```

Планировщик запускается вместе с ботом и дальше работает сам. подборка по понедельникам, напоминание за день до события и вопрос о посещении после него, а по пятницам напоминание тем, кто ещё ничего не выбрал на неделю

## Данные

Три таблицы в PostgreSQL:

- `users` - профиль: стрик, заморозки, категории, пушкинская карта
- `events` - афиша: название, категория, место, дата, цена, ссылка на билет
- `user_challenges` - связь пользователя и события и его статус: `offered -> accepted -> confirmed`, либо skipped/missed

Внешних интеграций нет, всё хранится бд. События пока добавляются вручную как мок данные для MVP, к реальным афишам обращений нет

## Запуск

Нужен Docker с Docker Compose

```
cp .env.example .env   # вписать токен и данные для бд
docker compose up --build
```

Поднимутся PostgreSQL и бот, миграции применятся автоматически при старте

Переменные в `.env`: `BOT_TOKEN`, `ADMIN_IDS` (id админов через запятую, для доступа к `/admin`) и доступы к базе - `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB`. `DATABASE_URL` в Compose собирается автоматически. Сам `.env` в `.gitignore`, в репозитории только пример

## Как проверить

Открыть бота и пройти по шагам: выбрать категории -> "Готово" -> ответить про пушкинскую карту -> завершить регистрацию. Дальше открывается подборка, по нажатию ❤️ событие попадает в "Мои мероприятия", и бот обещает напомнить. В меню доступны свои мероприятия, стрик и смена категорий

Рассылки и напоминания можно проверить через `/admin`, вписав свой id в `ADMIN_IDS`

## Ограничения

- События демонстрационные, живой афиши нет. Пушкинская карта проставляется вручную
- Бот не продаёт билеты и не знает баланс карты, покупка происходит по ссылке на стороне
- Факт посещения и оценка фиксируются со слов пользователя
- Один инстанс, без масштабирования
